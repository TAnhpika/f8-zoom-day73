# Data fetching

2 kiểu lấy dữ liệu:

1. từ server component

- Gọi trực tiếp vào server component (dùng await)
- Dùng fetch (Khuyến nghị của Next)

2. Client Component

- Giống như React
- Axios, Tanstack Query, useEffect

Biến môi trường:

- SERVER_API=https://dummyjson.com # Chỉ đọc đc ở server
- NEXT_PUBLIC_APP_NAME=F8 # Đọc cả client và server (k để thông tin nhạy cảm)

- đã thay thẻ img = component Image (tối ưu sẵn hiệu năng)

- next k cho gọi API ngoài để tối ưu hiệu năng -> chỉnh trong next config

```json
images: {
        remotePatterns: [
            {
                hostname: "cdn.dummyjson.com",
            },
        ],
    },
```

### Loading

- loading.jsx sẽ có scope trong folder chứa nó (k đc trong folder con)
- nếu để ở app: global loading
- tự tối ưu UX: chỉ hiện khi action nặng như gọi API

### error

- tạo error.jsx
- phải dùng "use client"

### Not found

- not-found.jsx
- có sẵn hàm notFound để gọi notFound ở bất cứ đâu
